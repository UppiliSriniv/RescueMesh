RescueMesh – Intelligent Rescue Through Connected Robotics

A self-healing, communication-aware multi-agent rescue system for GPS-denied underground environments.

Built for underground mines, tunnels, and collapsed structures, RescueMesh treats exploration and connectivity as ONE problem—combining a ground-based wheeled rover, an aerial drone, wireless relay nodes, environmental sensors, and local store-and-forward fallback.

Traffic Separation & Reliability

Video (Wi-Fi) and short telemetry/alerts (relay nodes) are handled separately; relay packets never carry live video. Reliability uses application ACKs, sequence IDs, retries, duplicate suppression, store-and-forward buffering, local logging, and a command watchdog.

ESP-NOW Multi-Hop Note

ESP-NOW does not automatically provide a multi-hop mesh; application-level routing, hop selection, and delivery confirmation must be implemented if ESP-NOW is used.
